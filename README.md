# 📝 Fullstack Blog App

## 📖 概要
このブログアプリは、**バックエンドを触ってみたかった**という動機から、ハンズオン形式で作成しました。

以下の YouTube 動画を参考にして構築しました：  
📺 [モダンな技術でフルスタックブログ開発をしてみよう【Next.js13/Prisma/Supabase/Typescriptを利用】](https://www.youtube.com/watch?v=wF3g76z14Gs)

---

## 🛠 使用技術スタック

| 分野 | 技術 |
|------|------|
| フロントエンド | **Next.js 13**, **TypeScript** |
| バックエンド / API | **Next.js API Routes**, **Prisma (ORM)** |
| データベース | **PostgreSQL（Supabase）** |
| ユーザー認証 | **Supabase Auth (Email/Password)** |
| その他 | **React**, **Axios**, **Tailwind CSS** |
